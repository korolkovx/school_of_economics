ГРАФИК ДОПУСТИМЫХ РЕШЕНИЙ

Каждое неравенство задает прямую линию на координатной плоскости. Область под обеими прямыми — это зона возможных рецептов крафта.

📌 ТЕОРЕМА О ВЕРШИНАХ (ФУНДАМЕНТ ЭКОНОМИКИ):
Вам не нужно проверять тысячи вариантов вручную. Максимальная выгода всегда находится в одном из углов (вершин) допустимой фигуры.
Точка пересечения прямых находится решением простой школьной системы уравнений:
{ 2x + y = 100
{ x + 3y = 80
x = 44 шт., y = 12 шт. Прибыль = 44·10 + 12·15 = 620 💰

ПРОВЕРЬ СЕБЯ: ЗАДАНИЕ ОГЭ №13

ФИПИ ТРЕНАЖЕР

Решите систему линейных неравенств, аналогичную лимитам крафта:

{ 2x - 8 ≤ 0
{ 3x + 6 > 0
1) (−∞; −2) ✖
2) (−2; 4] ✔
3) [−2; 4) ✖
4) (4; +∞) ✖
🎉 ВЕРНО! +1 БАЛЛ К ОГЭ!
Решение: 2x ≤ 8 ⇒ x ≤ 4. Второе: 3x > −6 ⇒ x > −2.
Пересечение луча и полуинтервала дает (−2; 4]. Теперь ты видишь, что школьные неравенства — это просто правила игры, которые ты только что хакнул!
